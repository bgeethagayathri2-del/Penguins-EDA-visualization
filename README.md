# Penguins: Exploratory Data Analysis

Explores the Palmer Penguins dataset with cleaning, statistics and visualizations to find patterns between species, islands, sex and body measurements.

- **Dataset:** Palmer Penguins (from seaborn), 344 rows and 7 columns
- **Data cleaning:** 11 rows had missing values (2 penguins had no measurements at all, and 11 rows were missing sex). These rows were removed, which left 333 rows.
- **Techniques:** summary statistics, count plots, histograms, box plots, correlation heatmap, pair plot, group averages
- **Summary statistics:** average body mass is about 4,202 g (range 2,700 to 6,300 g), average flipper length is about 201 mm, and average bill length is about 43.9 mm.
